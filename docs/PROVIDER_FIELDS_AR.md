# بيانات مزود JokStream

إذا كان اشتراكك يدعم Xtream Codes، جهّز هذه الحقول الثلاثة:

| الحقل | ما الذي تضعه؟ |
|---|---|
| Server URL | رابط الخادم الذي أعطاك إياه المزود |
| Username | اسم مستخدم الاشتراك |
| Password | كلمة مرور الاشتراك |

هذا يكفي كبنية بيانات Xtream. **لا يلزم رابط M3U إضافي**.

إذا كان المزود أعطاك رابط M3U فقط ولم يعطك اسم مستخدم وكلمة مرور Xtream، فهذا نوع إعداد مختلف ويحتاج إلى دعم منفصل.

## حماية البيانات

لا تلصق بياناتك في:
- محادثة ChatGPT.
- ملفات `.env.example` أو أي ملف داخل Git.
- كود React أو متغيرات `VITE_*`.
- مستودع GitHub العام.

توضع بيانات المزود في Secrets على الخادم الخاص فقط. في هذه النسخة الأولية لا توجد بعد شاشة إدارة آمنة لحفظها من المتصفح؛ لذلك لا تدخلها في لوحة الموقع أو GitHub حالياً.
